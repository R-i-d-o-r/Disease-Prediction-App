# 🩺 AI Disease Prediction App

An AI-powered disease prediction app that predicts possible diseases based on user symptoms — built entirely from a **phone** using Python, Scikit-learn, and Gradio.  

## 🚀 Features
- 4 ML Models: Decision Tree 🌳, Random Forest 🌲, SVM ⚙️, Naive Bayes 📈  
- Automatic feature encoding  
- Balanced dataset using RandomOverSampler  
- Web UI powered by Gradio  

## 🧠 How it Works
1. Enter your symptoms (comma-separated)
2. The models predict individually
3. The app returns their combined (mode) prediction
